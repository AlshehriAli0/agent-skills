# lahjh

Write Saudi Arabic for apps and websites, so localized strings read like a Saudi content writer wrote them rather than like English wearing Arabic words.

- [`SKILL.md`](SKILL.md) — the procedure: brief the project once, then triage, place, register, verb, name, cut, round-trip per string, then sweep the set.
- [`references/CONTEXT-MINING.md`](references/CONTEXT-MINING.md) — the seven rungs of context, and how to work when there is only a JSON file.
- [`references/EXAMPLES.md`](references/EXAMPLES.md) — shipped strings by slot, each annotated with the move behind it.
- [`references/ARINJIYAH.md`](references/ARINJIYAH.md) — the diagnostic layer for strings that are grammatical and still read as translated.

Built from ثمانية's published writing rules and shipped product copy, «العرنجية» (الترجمان أحمد الغامدي، تكوين، 2021)، and the sociolinguistics of the white Saudi dialect. The sourced dossier and test runs stay local in `.research/`, gitignored.
